Objetivo

Medir PM2.5 y PM10, temperatura y humedad; guardar las mediciones y mostrarlas en tiempo real; y avisar cuando la calidad del aire pueda afectar la salud.

  • ODS 3 Salud y bienestar
  • ODS 11 Ciudades y comunidades sostenibles
  • ODS 13 Acción por el clima

Cómo funciona

  1. El sensor midePM2.5, PM10, temperatura y humedad, cada pocos segundos.
  2. Envía a la nubePor Wi-Fi las mediciones llegan al servidor y se guardan.
  3. Se analizanSe calcula el ICA con la Res. 2254/2017 y reglas fijas evalúan las alertas.Además, un modelo experimental muestra un replay histórico del PM2.5 a 4 y 5 horas con datos de estaciones de referencia del IDEAM (no es un pronóstico en tiempo real) y, en pruebas con datos simulados, un modelo busca lecturas anómalas.
  4. Recibes el avisoSi te suscribes, te llega un correo cuando se abre una alerta.

Estación de bajo costo; no sustituye mediciones oficiales. Algunas pruebas usan datos simulados y se indican como tal.
